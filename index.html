01 / SCOPE

제공 범위와 준비 상태

이 페이지에서 실제로 동작하는 기능은 작동 데모로 표시된 항목뿐입니다.

  • 이번 작동 데모

    CSV 주문 검증·매출 요약

    CSV의 헤더·날짜·수량·단가를 검증하고, 유효 행 기준의 매출 합계와 품목별 요약을 계산합니다. 이 페이지 하단에서 합성 샘플로 직접 확인할 수 있습니다.

  • 구축 상담용 설계

    문의·견적·후속업무 관리

    문의 접수, 견적, 후속 연락 일정을 한 곳에서 정리하는 구성안입니다. 아직 이 페이지에서 동작하지 않으며, 상담을 통해 범위를 확정합니다.

  • 기존 샘플 · DOCX 시각검수 중

    회의메모·실행항목 정리

    회의 메모에서 실행 항목을 정리하는 기존 샘플이 있습니다. 산출물 서식의 시각 검수를 진행 중이며, 이 페이지에서는 동작하지 않습니다.

구현되지 않은 카드를 작동하는 기능으로 표현하지 않습니다. 가격과 납기는 입력 형식·업무 범위를 확인한 뒤 견적으로 안내합니다.

02 / LIVE DEMO

CSV 주문 검증·매출 요약

입력한 CSV는 이 브라우저 안에서만 처리됩니다. 외부로 전송하지 않고, 자동 저장하거나 브라우저 저장소(localStorage)에 보관하지 않습니다. 원본 파일은 수정하지 않습니다.

입력 제한 · 파일 크기 1MB 이하 · 데이터 행 최대 5,000행

필수 헤더 · order_id,date,item,quantity,unit_price

쉼표 구분, UTF-8 인코딩. 날짜는 YYYY-MM-DD 형식의 실제 달력 날짜여야 합니다. 이 데모는 주문 ID당 1행, 원화 정수 단가를 기준으로 하며 반품·할인·세금 계산은 포함하지 않습니다.

파일을 선택하면 내용을 위 입력란에 불러옵니다. 파일은 이 브라우저 안에서만 읽습니다.

결과

아직 실행하지 않았습니다. 합성샘플을 불러오거나 CSV를 입력한 뒤 “검증·요약 실행”을 눌러 주세요.

정상행과 오류 보고서는 각각 해당 행이 있을 때 내려받을 수 있습니다. 좁은 화면에서는 표를 좌우로 움직여 확인하세요.

03 / PROCESS

상담·구축 흐름

  1. 파일 구조 확인 — 사용하는 파일의 열 이름과 의미를 확인합니다.
  2. 범위 합의 — 이번 작업에서 다룰 업무와 제외할 업무를 정합니다.
  3. 합성/익명 샘플 검증 — 합성 또는 익명 처리한 샘플로 결과를 확인합니다.
  4. 구축·검수 — 합의한 범위대로 만들고 함께 검수합니다.
  5. 가이드 인계 — 사용 방법을 문서로 정리해 인계합니다.
04 / NEXT STEP

구축 요청서 템플릿

업무 내용, 입력 열, 원하는 결과, 처리 빈도, 실행 환경, 희망 기한, 예산 범위를 직접 정리할 수 있는 텍스트 템플릿입니다.
